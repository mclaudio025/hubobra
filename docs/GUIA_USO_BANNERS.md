# Guia de Uso - Sistema de Banners Dinâmicos

## Introdução

Este guia explica como usar o sistema de banners dinâmicos para gerenciar o conteúdo promocional da loja sem necessidade de conhecimento técnico.

## Acesso ao Sistema

### 1. Login Administrativo
- Acesse: `http://localhost:3000/login`
- Use suas credenciais de administrador
- Após o login, você será redirecionado para o painel administrativo

### 2. Navegação para Banners
- No painel administrativo, clique em **"Banners"**
- Você verá a lista de todos os banners existentes

## Tipos de Banners

### 🎯 Hero Banners
- **Onde aparecem:** Carrossel principal da homepage
- **Características:** Imagens grandes, destaque máximo
- **Recomendação:** Use para promoções principais e lançamentos

### 🎨 Banners Promocionais
- **Onde aparecem:** Seção de promoções da homepage
- **Características:** Grid de 3 colunas, visual atrativo
- **Recomendação:** Use para ofertas especiais e categorias

### 🏪 Banners de Departamento
- **Onde aparecem:** Seção de departamentos especiais
- **Características:** Ícones circulares, layout compacto
- **Recomendação:** Use para destacar categorias específicas

## Como Criar um Novo Banner

### Passo 1: Acessar Criação
1. Na lista de banners, clique em **"Novo Banner"**
2. Você será direcionado para o formulário de criação

### Passo 2: Preencher Informações Básicas
- **Título:** Nome principal do banner (obrigatório)
- **Subtítulo:** Texto secundário (opcional)
- **Descrição:** Texto explicativo (opcional)
- **Tipo:** Escolha entre Hero, Promocional ou Departamento

### Passo 3: Configurar Ação
- **Texto do Botão:** Ex: "Ver Ofertas", "Comprar Agora"
- **Link do Botão:** URL para onde o usuário será direcionado

### Passo 4: Personalizar Visual
- **Upload de Imagem:** Clique para enviar uma imagem
- **Cor de Fundo:** Escolha uma cor ou gradiente
- **Cor do Texto:** Branco ou preto para melhor legibilidade

### Passo 5: Configurações Avançadas
- **Posição:** Ordem de exibição (menor número = primeira posição)
- **Status:** Ativo (visível) ou Inativo (oculto)
- **Datas:** Período de exibição (opcional)

### Passo 6: Preview e Salvar
- Use o **Preview** para ver como ficará
- Clique em **"Salvar"** para criar o banner

## Como Editar um Banner Existente

### Método 1: Lista de Banners
1. Na lista, clique no **ícone de edição** (lápis) do banner desejado
2. Faça as alterações necessárias
3. Clique em **"Salvar Alterações"**

### Método 2: Visualização Detalhada
1. Clique no **nome do banner** na lista
2. Na página de detalhes, clique em **"Editar"**
3. Faça as alterações e salve

## Gerenciamento Rápido

### Ativar/Desativar Banner
- **Na lista:** Use o botão de toggle (olho)
- **Na visualização:** Clique em "Ativar" ou "Desativar"
- **Efeito:** Banner some/aparece imediatamente no site

### Reordenar Banners
1. Na lista de banners, use os números de posição
2. Banners com posição menor aparecem primeiro
3. Edite a posição para reordenar

### Excluir Banner
1. Acesse a visualização detalhada do banner
2. Clique em **"Excluir"** (botão vermelho)
3. Confirme a exclusão
4. ⚠️ **Atenção:** Esta ação não pode ser desfeita

## Dicas e Boas Práticas

### 📸 Imagens
- **Tamanho recomendado:** 1920x600px para Hero Banners
- **Formato:** JPG ou PNG
- **Qualidade:** Alta resolução, mas otimizada para web
- **Conteúdo:** Evite texto na imagem (use os campos de texto)

### 🎨 Design
- **Contraste:** Certifique-se que o texto seja legível
- **Consistência:** Mantenha um padrão visual entre banners
- **Simplicidade:** Mensagens claras e diretas funcionam melhor

### 📱 Responsividade
- **Teste:** Visualize em diferentes tamanhos de tela
- **Texto:** Evite textos muito longos
- **Imagens:** Certifique-se que funcionam em mobile

### ⏰ Agendamento
- **Promoções:** Configure datas de início e fim
- **Eventos:** Prepare banners com antecedência
- **Sazonalidade:** Atualize conforme as estações

## Solução de Problemas

### Banner não aparece no site
1. ✅ Verifique se está **Ativo**
2. ✅ Confirme o **Tipo** correto
3. ✅ Verifique as **Datas** (se configuradas)
4. ✅ Aguarde alguns segundos para atualização

### Imagem não carrega
1. ✅ Verifique o tamanho do arquivo (máx. 5MB)
2. ✅ Use formatos JPG ou PNG
3. ✅ Tente fazer upload novamente

### Preview não funciona
1. ✅ Preencha pelo menos o **Título**
2. ✅ Selecione um **Tipo** de banner
3. ✅ Aguarde o carregamento completo

### Texto não aparece bem
1. ✅ Ajuste a **Cor do Texto**
2. ✅ Teste diferentes **Cores de Fundo**
3. ✅ Use o **Preview** para verificar

## Fluxo de Trabalho Recomendado

### Para Promoções Regulares
1. **Planeje** com antecedência
2. **Crie** o banner como inativo
3. **Teste** usando o preview
4. **Ative** no momento certo
5. **Desative** quando a promoção acabar

### Para Campanhas Sazonais
1. **Prepare** todos os banners necessários
2. **Configure** datas de início e fim
3. **Monitore** a performance
4. **Ajuste** conforme necessário

### Para Testes A/B (futuro)
1. **Crie** duas versões do banner
2. **Ative** uma por vez
3. **Compare** resultados
4. **Mantenha** a melhor versão
