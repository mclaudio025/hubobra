## 💡 **Decisões Técnicas Tomadas**

### **✅ Arquitetura:**
- **Backend:** NestJS (TypeScript, modular, escalável)
- **Frontend:** Next.js 15 (SSR, performance, SEO)
- **Banco:** PostgreSQL (relacional, ACID, performance)
- **Cache:** Redis (sessões, cache de queries)
- **IA:** Sistema de personas (Lia + Zé da Obra)

### **✅ Integrações:**
- **Pagamentos:** Mercado Pago (PIX, cartão, boleto)
- **WhatsApp:** Evolution API (mensagens, webhook)
- **Email:** SMTP nativo (transacionais)
- **Upload:** Sistema próprio (seguro, otimizado)

### **✅ Hospedagem & Infraestrutura:**
- **Escolhida:** VPS Contabo com Easypanel (Docker)
- **Banco de Dados & Storage:** Supabase Cloud (PostgreSQL + CDN)
- **Deploy:** Git + GitHub conectado ao Easypanel
